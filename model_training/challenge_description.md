# TEMPORAL AI CHALLENGE — Give AI a Sense of Time

LLMs read text. The real world speaks in signals: vitals, sensors, markets, grids.

This weekend, you'll build AI that understands how the world changes over time.

## 🎯 The Mission

Use Aionic's **TimeNet** to prepare open-source time-series data, then train a **TSLM (Time-Series Language Model)** that connects temporal signals with language for a useful task.

Think:

- A patient's condition changing 🏥
- A machine starting to fail 🏭
- Energy demand shifting ⚡
- Anywhere people act on signals

## 🛠️ From Problem to Proof — 4 Steps

### 1️⃣ Problem + Data

Pick a target user and problem, then source open data.

**Agentic dataset-hunting pipelines encouraged.**

### 2️⃣ Connect

Build or use a **TimeNet connector** for:

- Signals
- Metadata
- Annotations

Reusable ingestion pipelines are welcome.

### 3️⃣ Train + Evaluate

Train or fine-tune a TSLM and compare it against a baseline on held-out data.

**Avoid leakage across:**

- Time
- Subjects
- Devices

### 4️⃣ Demonstrate

Show:

- Real inputs
- Model outputs
- How it helps your user
- Supporting evidence
- Limitations

## 📦 You Submit

- ✅ Working demo
- ✅ Code + training config
- ✅ Checkpoint or adapter
- ✅ Dataset docs
- ✅ Short evaluation with baseline

Then give a **live demo to the jury** covering:

- Problem
