## Goal

```text
approved source
→ verified acquisition
→ SourceDescriptor
→ OnboardingOrchestrator
→ semantic onboarding
→ NEEDS_HUMAN_RESOLUTION if required
→ native TimeNet connector/build
→ TimeF
→ verification
→ imported-record frontend APIs
```
